- [ ] Teach-from-zero ≥95% in 30-student panel (vs Sayo ~70%, Khan ~60%)
- [ ] Dynamic lab with live experiment (vs PhET static, Sayo video)
- [ ] Bilingual instant toggle EN ⇄ 繁中 (vs Sayo EN-only, Khan translation lag)
- [ ] 0 broken links / 0 console errors / 0 404s
- [ ] Mobile responsive 375px (vs Brilliant desktop-first)
- [ ] Loading < 1.5s (vs Khan 3s+, PhET 5s+)
- [ ] Subscribe CTA working with real Stripe (vs Sayo vaporware)
- [ ] 30-second "wow" moment (vs Khan 5-min explanation)
- [ ] Accessibility AAA (keyboard, screen reader, contrast)
- [ ] Analytics: time-on-task ≥8 min (vs industry 3 min)
- [ ] Offline capable (PWA or cached)
- [ ] Parent dashboard preview
- [ ] Teacher assignment mode
- [ ] AI tutor chat integrated
- [ ] Gamification: badges, streaks, leaderboards
