學習目標

  • 用 n = m / Mr，以及 c = n / V，計算溶液濃度。V 先換算成 dm³。
  • 判斷哪種固體適合作基準物。
  • 判斷體積讀數和溶質轉移誤差會令濃度偏高還是偏低。

操作

  • 調質量、選擇體積和固體，讀畫面上的 n 和 c。
  • 把滑桿設成 2.65 g、250 cm³、無水碳酸鈉，再按核對。
  • 選一個誤差，判斷濃度偏高或偏低。沒有溶解、加熱或配製步驟。

錯因

  • 液面低於刻度仍當成正確體積：實際體積偏小，濃度偏高。
  • 固體沒有全部轉移：溶質偏少，濃度偏低。
  • 十水碳酸鈉誤用無水的 Mr 106：摩爾數算大了，濃度偏高。

調質量和體積。基準例子是 2.65 g 無水碳酸鈉配成 250 cm³。

標準溶液計算

c = 1000m / (Mr × V)。m 的單位是 g，V 的單位是 cm³，Mr 用 g/mol。無水碳酸鈉的課堂 Mr 取 106。
