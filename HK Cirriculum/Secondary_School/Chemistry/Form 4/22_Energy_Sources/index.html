學習目標

  • 用使用時的方程式比較甲烷、乙醇和氫。
  • 判斷這一步有沒有 CO₂。
  • 判斷 ΔH 為負，並把製造氫的反應分開。

先看三條使用式，再為每一種選 CO₂ 和 ΔH 的符號。

化石燃料與可再生能源

操作：每種都選使用這一步有沒有 CO₂，以及 ΔH 是負、零還是正，然後核對。答錯會寫出錯因。有沒有 CO₂，看使用式裡有沒有碳。這三條使用式都是與氧化合而放熱，ΔH 為負；符號不會因為原料能否再形成而變成零。這裡只比較方程式，沒有點火或製備步驟。

甲烷（化石燃料）

天然氣的主要成分。碳來自古代生物質，不能靠短時間的同一過程補回。煤是另一種化石燃料，主要可看成 C + O₂ → CO₂；含硫時還有 S + O₂ → SO₂。這一欄只判斷甲烷的使用式。

乙醇（碳可再被植物固定）

可由糖發酵得到：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂。光合作用把二氧化碳固定成糖：6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂。按鈕只判斷上面的燃燒式。

氫（能量載體）

製造氫可以是 CH₄ + 2H₂O → CO₂ + 4H₂，也可以是電解 2H₂O → 2H₂ + O₂，電解要加入電能。按鈕只判斷上面的使用式，不把製造式的產物算進去。
