# LGER Framework

**L - Learn (教學)**
- Teach-from-zero 6-step intro
- Concept explanation with visuals
- Formula/theory derivation
- Real-world context

**G - Guided (引導)**
- 3+ interactive challenges
- Instant feedback
- Progressive difficulty
- Hint system

**E - Experiment (實驗)**
- Dynamic interactive web application
- Live simulation (canvas/SVG/Three.js)
- Parameter manipulation
- Data collection

**R - Review (複習)**
- Summary of key concepts
- Self-assessment quiz
- Real-world application
- Extension challenges
